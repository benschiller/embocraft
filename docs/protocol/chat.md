# 文字聊天

> **Floperati 分支：** 语音栈（语音识别、语音合成、语音留言、附近空间语音、点对点语音信令、Agent 语音回复与头顶字幕）已整体移除。聊天只保留文字。

进入世界后，右下角提供文字聊天面板。聊天通过 Colyseus 世界房间的 `chat` 动作发送，不经过任何 HTTP 路由。

## 聊天模式

| 模式         | 交互规则与配额限制                                                                                                                                       | 接收范围与 Agent 表现                                                                         |
| :----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------- |
| **公开群聊** | 输入文本回车即发，最大长度 **240 字符**。群聊支持 `@` 提及玩家（作为醒目标识，不限制消息可见性）。                                                       | 全世界在线真人与 Agent 均可接收。触发 Agent 思考轮次。                                        |
| **定向私信** | 点击 `@` 按钮或输入 `@` 检索在线玩家/Agent（支持键盘上下键选择，**上限 8 位**）。必须显式选中接收者标签才允许发送。若昵称重复自动展示 Session 尾号区分。 | **服务端严格按接收者名单过滤**。其他旁观者及未被 `@` 的 Agent 的 `observe` 历史中绝对不可见。 |

- 同一玩家两条消息之间至少间隔 **300 ms**（`CHAT_MIN_INTERVAL_MS`）。
- Web 端本地最多保留 **50 条** 最近消息，页面刷新或重新入房不补发历史消息。
- 聊天记录（发送者、范围、接收者、文本）写入 PostgreSQL 的 `ChatMessage` 表。

## 协议

```json
{ "type": "chat", "payload": { "text": "你好", "scope": "private", "recipients": ["<sessionId>"] } }
```

- `scope` 为 `public`（默认）或 `private`；私聊需要 `1..8` 个互不重复、当前在线且非发送者自身的会话 ID。
- 入房或重连时服务端下发 `chat.auth` 令牌；Floperati 分支中它不再用于任何 HTTP 路由，仅为协议兼容保留。
- 历史数据中可能存在 `scope: "nearby"` 的旧记录（附近语音转写）；新版本不再产生此类消息，Agent 对其回复时会限定为私聊发给原发送者。
